# dsh-tell-the-diff

DSH 的**会话路线图「这一路」**：模型埋头执行时，让用户不用追问主对话也知道——哪里落了地、哪里卡住换了路、此刻是什么状态。

0.3.0 只做确定性路径：读会话日志，不调用任何模型，不额外消耗 token。

## 它长什么样

**输入框下方一行**：`● 这一路 · 验证通过 · pnpm test … 打开`

右栏一张卡：

- **一行现状**：空闲时 `空闲 · 上一步 12 秒前结束`；进行中是最近一个落点
- **人话摘要**：模型通过 `tell_the_diff` 工具写的一句话
- **落点**：`● 验证通过 · pnpm test`、`● 新建了文件 · a.md`、`● 改动了代码 · 3 个文件`、`● 子代理交回结果`、`● 提交了一次`
- **岔路**：`⑂ 卡住了 · 「pnpm test」试了 2 次没通`、`⑂ 换过路 · …换了做法`
- **计划**：模型写过 `todo_write` / `tell_the_diff` 就用它（标「模型自己写的」）；没写就按动作推断（标「按动作推断」）
- **需要你决定 / 可能的风险 / 还没解决的问题**
- **角落一行**：文件数、动作数、出错数

## 为什么只画落点

`read → grep → edit` 是准确的，但对读者没有意义：它说的是"跑了什么"，没说是"为了什么"。"发生了什么"这一层已经被 DSH 轨迹和 dsh-context（文件活动 / 命令执行）占满；没人占的那格是**变化**——哪些路被关掉了。

落点 = 工作状态确实改变的瞬间（测试转绿、文件落地、子代理交回、提交）；岔路 = 试过、没通、换了做法。

## 怎么开

三个入口，共用同一张卡片：

1. **输入框下方一行**（最省事）：点「打开」进右栏。
2. **右栏标签条**：与 `dsh-context`、文件、Git 等同一排。
3. **右栏起始页**：卡片入口。

## 数据从哪来

| 来源 | 提供什么 | 是否调模型 |
|---|---|---|
| `session/event` 事件流 | 工具调用、结果、文件落点、轮次 | 否 |
| `todo_write` / `tell_the_diff` | 模型自己的计划与人话摘要 | 否（模型本来就在说话） |
| `GET /dsh-tell-the-diff/state?session=<id>` 轮询 | 合成卡片 | 否 |

服务端只为每个会话保留一份派生状态（最多 40 个会话，空闲 30 分钟回收），未知会话首次读取时从日志最近 400 条事件重建。

## `tell_the_diff` 工具

模型在任务开始、阶段切换、遇到阻塞、长任务每推进一段时调用一次：

```json
{
  "plain": "在核对需求，还没动代码；等一下要先确认旧接口要不要保留。",
  "steps": [{ "title": "读现状", "status": "done" }, { "title": "改代码", "status": "doing" }],
  "questions": ["旧接口还要兼容吗？"],
  "risks": ["改动会影响两个下游脚本"]
}
```

工具描述里写死了两条纪律：**用非技术读者能懂的话**；**不要用比喻、黑话、文件名清单或代码术语**。

## 边界

- 只读、旁路：不改任务执行，不自动发消息，不自动审批，不抢主对话。
- 不复制文件树 / Git / 子代理视图（`dsh-better-sidebar` 的事）。
- 不重复上下文与命令统计（`dsh-context` 的事）。
- 不做跨会话方位（`bearings` 的事）。
- 不录制全量 transcript。

## 已知限制

- 轮询 1.5 秒一次，不做推送。
- 岔路是启发式：连续失败 ≥2 次才算，且 `卡住了`/`换过路` 两种状态分开标。
- 「还没解决的问题」区块的标题走字典；其余文案跟随 `ctx.locale`。
- 介入时机函数 `shouldSurface` 目前只到 `card`，面板不主动弹窗。

## 开发

```sh
npm test          # node --test，59 个用例
```

插件源码在 `plugin/`，纯函数核心在 `plugin/core/`：`monitor.js`（事件归约）、`episodes.js`（用途归并）、`roadmap.js`（落点与岔路）、`store.js`（会话级缓存）。

## 安装

DSH 插件管理里「添加插件 → 本地目录」，选中 `plugin/`；或让 DSH 用 `plugin_manager` 的 `install_bundle` 安装这个绝对路径。装完需重启一次 DSH。
